# Центр Пожтехника

Корпоративный сайт для [ООО «ЦентрПожТехника»](https://centrpozhtech.ru) — компании, которая занимается пожарной безопасностью в Москве.

## Что на сайте

Одностраничный SPA с секциями:

- **Главная** — герой-баннер с GSAP-анимациями
- **О нас** — миссия, лицензии (МЧС № 77-Б/01441), статистика
- **Услуги** — пожарная сигнализация, пожаротушение, видеонаблюдение, ТО
- **Прайс** — подробные таблицы цен (огнетушители, рукава, лестницы, обучение и т.д.)
- **Контакты** — карта (OpenLayers), телефон, WhatsApp, email

Плюс страница 404 с собственным хедером/футером и прелоадер при загрузке.

## Стек

| | |
|---|---|
| Фреймворк | Next.js 15 (App Router) |
| Язык | TypeScript |
| Стили | Tailwind CSS |
| UI-компоненты | shadcn/ui (Radix) |
| Анимации | GSAP + ScrollTrigger |
| Карта | OpenLayers (OSM) |
| Иконки | Lucide React |

## Запуск

```bash
npm install
npm run dev
```

Сайт будет на `http://localhost:3000`.

## Сборка

```bash
npm run build
```

Билд в формате `standalone` — можно деплоить как простой Node.js-сервер.

## Структура

```
app/
  layout.tsx          # Корневой layout (шрифты, мета, обёртки)
  page.tsx            # Главная страница
  not-found.tsx       # Кастомная 404
  context/            # React-контекст для выбора услуги
components/
  header.tsx          # Шапка (фиксированная, с мобильным меню)
  hero.tsx            # Герой-секция
  about.tsx           # О компании
  services.tsx        # Услуги (табы)
  price-list.tsx      # Прайс-лист
  contact.tsx         # Контакты
  contact-modal.tsx   # Модалка «Позвонить»
  map.tsx             # Карта OpenLayers
  footer.tsx          # Подвал
  preloader.tsx       # Анимация загрузки
  mickey-mouse.tsx    # Анимированный Микки (ходит по экрану)
  scroll-animations.tsx
  image-gallery.tsx   # Лайтбокс для сертификатов
  ui/                 # shadcn/ui компоненты
styles/               # Глобальные CSS
public/               # Статика (иконки, изображения)
```
